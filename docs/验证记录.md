# AB 日志分析网页验证记录

日期：2026 年 9 月 11 日。交付版本：1.4.0。

## 结论

真实日志导入、后台解析、独立分析、配对比较、图表与原文联动、筛选和 CSV / TXT 下载已验证。交付是可用工具网页，内置演示不包含用户原始样本。

本次引擎测试 59 项通过，其中 57 项为可复现的合成案例，2 项为用户提供日志的样本回归；不提供样本路径时，持续集成运行 57 项。原浏览器回归 61 项、跳变展示专项 24 项、原文浏览专项 33 项、间隔与历史专项 42 项通过，共 160 项。静态入口、相对资源路径、JavaScript 语法检查通过。

1.1 新增序号与原文字节的对应显示：HEX / 十进制双显、图表进制切换、8 字节帧头说明、序号字段精确高亮和字节跳转，以及 CSV / TXT 中的对应字段。

1.2 修复持续序号回退被累计为大量补到与同号异内容的问题。回退保守分段，界面与导出明确“段内统计，段间待核对”，并展示边界前后序号及原文。不把回退直接认定为设备重启。

1.3 支持普通报文点击和完整原文浏览。选择原文行时，序号字节、帧头、命令 / Key 与源行同步更新；非有效报文行清空解析。异常计算与配对基线保持不变。

1.3.1 修正数值增大却称为“持续回退”的误导性表述，统一使用“序号跳变待核对”，分开展示观测到的数值变化和待核对状态。算法仍保守分段，不将较短候选距离当成已确认的实际回退或丢包数量。

1.4 新增同一日志相邻有效报文的接收间隔，并增加保存完整原始文件的本机历史。刷新或正常重启浏览器后可重新打开单文件与配对任务，使用当前引擎重新分析；历史不上传服务器。

## 上包间隔与本机历史验收

- 时间差按接收顺序计算，跨命令、乱序、分片和多帧均保持正确；首包无上包，同时间戳为 0 ms，负数提示时间戳回退。跨段保留接收时间差，缺号范围参照帧与接收顺序的上包不会混淆。
- 详情、局部图表的普通点提示、原文帧头、复制及 CSV / TXT 使用相同间隔；0 和负数作为数值导出。选择诊断行时清除旧的间隔与命令 / Key。
- 保存后的原始字节与导入文件逐字一致；完整关闭浏览器再启动后，无需重新选择文件即可恢复。曾保存的旧版本统计被当前引擎的重新分析结果替代。
- 配对任务恢复后，两份日志仍按原来的出现次数匹配；过滤日志独立计算上包。重复导入相同名称和内容不会新增记录，同名不同内容保留两条。
- 保存开关可跨刷新保留；关闭自动保存后仍可手动保存。演示和取消的分析不产生历史。
- 模拟存储配额不足时，事务不会留下半条元数据或孤立文件，分析与导出继续可用；恢复存储后可重试成功。模拟 IndexedDB 不可用时仍能完成分析。
- 20 条上限的并发写入回归通过，512 MB 逻辑大小限制拒绝新增时保留已有记录。删除与清空的取消操作保留数据，确认后同步删除元数据及对应文件，不影响当前分析和磁盘原件。
- 按文件名搜索覆盖单文件和配对任务，忽略大小写。HTML 形式的文件名按纯文本显示并能正常恢复，1440、1280、375 像素宽度均无横向溢出。
- 52,428,861 字节的合成日志（235,107 帧）导入、分析并保存约 2.49 秒；完整浏览器重启后，从历史打开并重新分析约 1.96 秒。末包原文和上一有效报文源行可正确定位。这是本机一次测量，不是所有电脑的性能保证。

浏览器历史验收使用隔离的测试目录和合成日志；真实样本不写入用户正在使用的浏览器历史。自动化完成后清空该测试目录内本工具的历史。以上容量错误为故障注入，未声称写满真实磁盘配额或实际保存了 512 MB。

## 覆盖的规则与操作

- 连续、最终缺号、全部或部分乱序补到，以及发生在文件开头之前的小范围补到。
- 同帧重复、同号不同内容、不同内容再次重复、跨多个正常回绕周期。
- 回绕处补到、跨零点缺号范围、文件首尾不推算缺号、较大未决跨度保守分段。
- 全命令共用序号，筛选不改变缺号统计。
- 分片、多帧、CRLF / 空行 / 诊断文字、真实源行范围及分片原接收时间。
- CRC 错误、非法十六进制、损坏长度、文件末尾残帧及重定位。
- 按时间戳和完整帧逐次配对、重复次数、对应不唯一、共有帧顺序差异及双方单侧记录。
- 单份过滤日志、UTF-16 编码、加载后断网导入分析。
- 图表点击与键盘操作、正常回绕标记、60 条分页、类型和覆盖范围筛选。
- CSV 的 BOM 与中文表头、全部 / 当前筛选导出、TXT 原文上下文。
- 1440、1280、390 像素宽度下无页面整体横向溢出；原始十六进制区域自身允许横向滚动。
- 文件名和原文按纯文本显示；没有第三方请求、日志上传或浏览器错误。
- 取消后禁用最终结果导出，能够重新发起分析；本地文件方式也能运行同一套后台解析。
- 低 / 高字节来自不同分片、同一源行包含多个帧、消息体内出现相同字节、空白分隔和拆分十六进制字符时，序号锚点定位准确。
- 跨多个回绕和解析缓冲区整理后，原始序号字段的源行与字符位置仍准确；长分片折叠中保留序号字段所在行。
- 原文高亮保持时间戳和完整文字不变；字段已经可见时保留 AB 帧头，不做多余的横向滚动。
- 缺号只定位前后真实报文，CRC 错误帧不显示可信序号高亮。列表、图表、详情、复制和导出的 HEX / 十进制 / 原始字节关系一致。
