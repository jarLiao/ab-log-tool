# AB 日志分析网页验证记录

日期：2026 年 9 月 11 日。交付版本：1.3.0。

## 结论

真实日志导入、后台解析、独立分析、配对比较、图表与原文联动、筛选和 CSV / TXT 下载已验证。交付是可用工具网页，内置演示不包含用户原始样本。

引擎测试 50 项通过，其中 48 项为可复现的合成案例，2 项为用户提供日志的样本回归；不提供样本路径时，持续集成运行 48 项。原浏览器回归 61 项、原文浏览专项 33 项通过，共 94 项。静态入口、相对资源路径、JavaScript 语法检查通过。

1.1 新增序号与原文字节的对应显示：HEX / 十进制双显、图表进制切换、8 字节帧头说明、序号字段精确高亮和字节跳转，以及 CSV / TXT 中的对应字段。

1.2 修复持续序号回退被累计为大量补到与同号异内容的问题。回退保守分段，界面与导出明确“段内统计，段间待核对”，并展示边界前后序号及原文。不把回退直接认定为设备重启。

1.3 支持普通报文点击和完整原文浏览。选择原文行时，序号字节、帧头、命令 / Key 与源行同步更新；非有效报文行清空解析。异常计算与配对基线保持不变。

## 普通报文与完整日志验收

- 没有异常的文件默认展示第一条真实报文，图表仍显示完整范围；普通点、全图曲线、左右方向键和上一 / 下一报文均可选取有效记录。
- 当前报文在图中标出，详情、原文字节高亮、命令 / Key 同步；快速滚动或点击行后保持正确源行与滚动位置。
- 完整原文支持滚动、首尾、行号跳转、返回选中行、上下方向键；诊断与空行保留。一行多帧可分别选择，分片中的诊断行不继承相邻报文解析。
- 异常的前后原文仍可查看，浏览其他行后可以返回原异常及两侧关联片段；筛选为空时清除旧解析和多帧选择控件。
- 横向滚动时行号保持可见；1440、1280、375 像素宽及 812×375 横屏均无页面横向溢出。
- 50 MiB 文件的第 235,107 行可直接滚动定位，末行选择约 94 ms，页面保留少于 80 个日志行节点。耗时为本机一次测量，不作为其他电脑的性能保证。
- 300,002 个物理行的合成文件验证了滚动高度压缩后仍可到达最后一行，防止大文件超出浏览器滚动高度上限。
- 原始与过滤日志独立查看、加载后离线操作及 file:// 打开均通过。所有请求为页面静态资源和本机 Blob，无日志上传。

## 覆盖的规则与操作

- 连续、最终缺号、全部或部分乱序补到，以及发生在文件开头之前的小范围补到。
- 同帧重复、同号不同内容、不同内容再次重复、跨多个正常回绕周期。
- 回绕处补到、跨零点缺号范围、文件首尾不推算缺号、较大未决跨度保守分段。
- 全命令共用序号，筛选不改变缺号统计。
- 分片、多帧、CRLF / 空行 / 诊断文字、真实源行范围及分片原接收时间。
- CRC 错误、非法十六进制、损坏长度、文件末尾残帧及重定位。
- 按时间戳和完整帧逐次配对、重复次数、对应不唯一、共有帧顺序差异及双方单侧记录。
- 单份过滤日志、UTF-16 编码、加载后断网导入分析。
- 图表点击与键盘操作、正常回绕标记、60 条分页、类型和覆盖范围筛选。
- CSV 的 BOM 与中文表头、全部 / 当前筛选导出、TXT 原文上下文。
- 1440、1280、390 像素宽度下无页面整体横向溢出；原始十六进制区域自身允许横向滚动。
- 文件名和原文按纯文本显示；没有第三方请求、日志上传或浏览器错误。
- 取消后禁用最终结果导出，能够重新发起分析；本地文件方式也能运行同一套后台解析。
- 低 / 高字节来自不同分片、同一源行包含多个帧、消息体内出现相同字节、空白分隔和拆分十六进制字符时，序号锚点定位准确。
- 跨多个回绕和解析缓冲区整理后，原始序号字段的源行与字符位置仍准确；长分片折叠中保留序号字段所在行。
- 原文高亮保持时间戳和完整文字不变；字段已经可见时保留 AB 帧头，不做多余的横向滚动。
- 缺号只定位前后真实报文，CRC 错误帧不显示可信序号高亮。列表、图表、详情、复制和导出的 HEX / 十进制 / 原始字节关系一致。

## 规模与响应

测试浏览器：Chrome 152.0.7977.83，Windows。本机测量，不作为其他电脑的耗时保证。

生成日志每份 52,428,861 字节（约 50 MiB），235,107 帧，覆盖 3 次回绕。序号连续、CRC 有效。浏览器端仅运行实际工具代码，没有跳过解析或预置分析结果。

| 检查 | 实测 |
| --- | --- |
| 50 MiB 单文件：导入到显示结果 | 约 1.96 秒 |
| 两份 50 MiB 日志：导入、解析、配对和显示 | 约 4.57 秒 |
| 50 ms 界面定时器观测到的最大间隔 | 约 62 ms |
| 取消到返回导入状态 | 约 38 ms |

| 同规模配对结果 | 235,107 次匹配，无单侧或共有帧顺序差异 |
| 独立 Node 解析耗时（1.1 历史测量） | 2.176 秒 |
| 独立 Node 解析进程峰值常驻内存（1.1 历史测量） | 364.7 MiB |

Node 耗时与内存值保留自 1.1 历史基线，没有作为 1.3 的新测量；内存值由 Node v24.19.0 的进程资源使用统计取得，是独立解析进程的峰值常驻内存，不是 Chrome 全进程内存。其余表项为 1.3 浏览器回归结果，只测量主线程响应及操作耗时，未声称测得浏览器峰值内存。
