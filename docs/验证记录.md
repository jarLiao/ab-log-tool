## 覆盖的规则与操作

- 连续、最终缺号、全部或部分乱序补到，以及发生在文件开头之前的小范围补到。
- 同帧重复、同号不同内容、不同内容再次重复、跨多个正常回绕周期。
- 回绕处补到、跨零点缺号范围、文件首尾不推算缺号、较大未决跨度保守分段。
- 全命令共用序号，筛选不改变缺号统计。
- 分片、多帧、CRLF / 空行 / 诊断文字、真实源行范围及分片原接收时间。
- CRC 错误、非法十六进制、损坏长度、文件末尾残帧及重定位。
- 按时间戳和完整帧逐次配对、重复次数、对应不唯一、共有帧顺序差异及双方单侧记录。
- 单份过滤日志、UTF-16 编码、加载后断网导入分析。
- 图表点击与键盘操作、正常回绕标记、60 条分页、类型和覆盖范围筛选。
- CSV 的 BOM 与中文表头、全部 / 当前筛选导出、TXT 原文上下文。
- 1440、1280、390 像素宽度下无页面整体横向溢出；原始十六进制区域自身允许横向滚动。
- 文件名和原文按纯文本显示；没有第三方请求、日志上传或浏览器错误。
- 取消后禁用最终结果导出，能够重新发起分析；本地文件方式也能运行同一套后台解析。

## 规模与响应

测试浏览器：Chrome 152.0.7977.83，Windows。本机测量，不作为其他电脑的耗时保证。

生成日志每份 52,428,861 字节（约 50 MiB），235,107 帧，覆盖 3 次回绕。序号连续、CRC 有效。浏览器端仅运行实际工具代码，没有跳过解析或预置分析结果。

| 检查 | 实测 |
| --- | --- |
| 50 MiB 单文件：导入到显示结果 | 约 1.96 秒 |
| 两份 50 MiB 日志：导入、解析、配对和显示 | 约 4.1 秒 |
| 50 ms 界面定时器观测到的最大间隔 | 约 63 ms |
| 取消到返回导入状态 | 约 39 ms |
| 单文件分析结果 | 235,107 有效帧，缺号 / 乱序 / 重复均为 0 |
| 同规模配对结果 | 235,107 次匹配，无单侧或共有帧顺序差异 |
| 独立 Node 解析耗时 | 2.143 秒 |
| 独立 Node 解析进程峰值常驻内存 | 343.1 MiB |

内存值由 Node v24.19.0 的进程资源使用统计取得，是独立解析进程的峰值常驻内存，不是 Chrome 全进程内存。浏览器验证记录测量的是主线程响应及操作耗时，未声称测得浏览器峰值内存。

## 交付范围

GitHub Pages 工作流按官方静态站点流程配置，并只上传 dist/。目标 GitHub 仓库尚未创建，因此没有运行线上 Actions、绑定真实 Pages 地址或执行线上浏览器验收；交付的是可运行网页和可发布配置。

首次访问网址需要下载资源；没有添加离线缓存。未验证所有浏览器和任意超过验收规模的输入。周期判断仍遵循 [需求说明](需求说明.md) 中的连续连接前提与保守分段规则。

本机 artifacts/ 保存自动化 JSON、截图、下载校验文件及生成的规模日志，已通过忽略规则排除在源码提交和发布文件之外。外发源码与网页包均不包含原始样本或这些导出证据。
